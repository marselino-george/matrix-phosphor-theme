# Microsoft Marketplace listing copy

## Short description

A black-first Matrix-inspired phosphor theme for Visual Studio 2022/2026 and SQL Server Management Studio 22, with electric-green accents and readable syntax hierarchy.

## Full description

Matrix Phosphor is a dark, black-first color theme inspired by the phosphor-green terminal aesthetic of *The Matrix*. It combines true-black editor and tool-window surfaces with a restrained hierarchy of dark green, electric green, pale green, and mint-white syntax colors.

The theme reserves its brightest electric green for keywords, control flow, active states, and important actions. Types and namespaces use a softer pale green, functions use a focused phosphor green, strings use a warmer green, literals use a near-white tint, and comments remain deliberately subdued. This keeps the Matrix character without turning the entire interface into one uniform neon color.

### Supported products

- Visual Studio 2022
- Visual Studio 2026
- SQL Server Management Studio 22

Companion variants for Visual Studio Code, Windows Terminal/PowerShell, and Notepad++ are available in the public Matrix Phosphor GitHub repository.

### Highlights

- True-black primary editor, panel, tab, and tool-window surfaces
- Complete Visual Studio shell coverage, including modern `Shell` and `ShellInternal` colors
- Dedicated C#, XML, HTML, Razor, and SQL syntax classifications
- Explicit SSMS colors for SQL operators, strings, system functions, and system tables
- Readable document tabs without project-color borders
- Stable theme identity so upgrades replace the existing installation
- Theme-only VSIX with no executable extension code
- No telemetry, network requests, services, commands, or background tasks

After installation, restart the target application and select **Tools > Theme > Matrix Phosphor**.

Matrix Phosphor is an unofficial fan-made theme. It is not affiliated with or endorsed by Warner Bros., Village Roadshow Pictures, Microsoft, or the creators of *The Matrix*.
